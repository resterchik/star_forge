# 🌌 StarForge — Космическая Idle / Clicker игра

Кроссплатформенная игра на Flutter & Dart (Android & iOS) с полностью процедурной генерацией графики, текстур планет, частиц и звёздного неба через `CustomPainter`.

---

## 🚀 Особенности игры

1. **Процедурная графика (0 внешних картинок)**:
   - Все небесные тела (Астероид, Луна, Марс, Земля, Юпитер, Звезда, Нейтронная звезда, Чёрная дыра) отрисованы в реальном времени с кратерами, радиальными градиентами, свечением атмосферы и световыми бликами.
   - Динамическое звёздное небо с мерцанием и параллаксом.
   - Система взрыва частиц при тапе с физикой и гравитацией.
   - Всплывающие золотые показатели заработка.

2. **Игровая механика**:
   - Тапайте по космическому телу для сбора Звёздной Пыли (✨).
   - 4 ветки улучшений клика (Сила тапа, Мульти-тап, Мега-тап, Ультра-тап).
   - 4 ветки автодобычи (Дрон-сборщик, Станция, Фабрика, Генератор туманности).
   - 8 уникальных космических тел с растущими множителями дохода (до ×100).
   - Оффлайн-доход: игра рассчитывает добычу за время, пока приложение было закрыто (до 8 часов).
   - Автосохранение через `shared_preferences`.
   - Тактильный отклик (Haptic Feedback) при каждом тапе.

## 📂 Структура проекта

```
star_forge/
├── lib/
│   ├── main.dart                  # Точка входа, настройка ориентации и темы
│   ├── models/
│   │   └── game_state.dart        # Состояние игры, логика апгрейдов, сохранение
│   ├── painters/
│   │   ├── planet_painter.dart    # Процедурная отрисовка планет, свечения и кратеров
│   │   ├── star_field_painter.dart# Процедурный генератор звёздного неба
│   │   └── particle_painter.dart  # Физическая система частиц при клике
│   ├── screens/
│   │   ├── game_screen.dart       # Главный экран игры
│   │   ├── shop_screen.dart       # Магазин улучшений (Тап и Автодобыча)
│   │   ├── planets_screen.dart    # Экран разблокировки и выбора планет
│   │   └── stats_screen.dart      # Полная статистика игрока
│   ├── utils/
│   │   ├── constants.dart         # Цветовая палитра и константы
│   │   └── helpers.dart           # Математические утилиты
│   └── widgets/
│       ├── floating_text.dart     # Всплывающий текст с очками
│       ├── planet_widget.dart     # Интерактивный виджет планеты с анимацией
│       └── star_field_widget.dart # Анимированный фон космоса
├── test/
│   └── widget_test.dart           # Тесты интерфейса
└── pubspec.yaml                   # Зависимости и конфигурация
```

## 🛠️ Запуск в режиме разработки

```bash
# Перейдите в папку проекта
cd star_forge

# Установите зависимости
flutter pub get

# Проверьте код анализатором
flutter analyze

# Запустите тесты
flutter test

# Запустите на подключенном устройстве или эмуляторе
flutter run
```
